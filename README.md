📦 Android Toolbox

Android Toolbox est une collection de packs, d'outils et de ressources destinés principalement aux anciennes versions d'Android et aux ROM AOSP / Custom ROM.

L'objectif est de regrouper au même endroit des fichiers qui peuvent être difficiles à retrouver aujourd'hui, notamment pour les appareils anciens.

✨ Contenu

Le projet peut notamment contenir :

- 📱 Packs pour différentes versions d'Android
- 🧩 Outils et composants utiles aux anciennes ROM
- 📦 APK, ZIP et autres fichiers nécessaires
- 🔧 Ressources pour personnaliser ou compléter une ROM
- 📚 Documentation et guides

Le contenu peut varier selon les versions d'Android et les appareils concernés.

📥 Téléchargements

Les fichiers sont distribués via les Releases GitHub.

Chaque Release indique normalement :

- la version d'Android concernée ;
- les fichiers inclus ;
- la compatibilité connue ;
- les éventuelles instructions d'installation ;
- les avertissements ou limitations.

👉 Consulte les Releases pour télécharger les packs disponibles.

📱 Compatibilité

Android Toolbox est principalement orienté vers les anciennes versions d'Android et les environnements AOSP / Custom ROM.

La compatibilité dépend cependant du pack utilisé.

Avant toute installation, vérifie toujours :

- la version d'Android ;
- l'architecture de l'appareil (ARM / ARM64, etc.) ;
- la ROM utilisée ;
- le modèle de l'appareil ;
- les prérequis indiqués dans la Release.

⚠️ Avertissements

Certains fichiers peuvent modifier le fonctionnement du système Android.

Fais toujours une sauvegarde avant d'effectuer une modification importante de ta ROM ou de tes partitions.

Un fichier compatible avec une version d'Android peut ne pas l'être avec une autre.

En cas de doute, vérifie la documentation du pack concerné avant de l'utiliser.

🎯 Objectif du projet

Android Toolbox a pour objectif de centraliser des ressources utiles pour les anciennes générations d'Android, afin qu'elles restent plus facilement accessibles et documentées.
